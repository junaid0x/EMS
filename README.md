# Employee Management System (EMS)

A modern full-stack Employee Management System (EMS) built to streamline workforce management for small and medium-sized businesses. The application provides a centralised platform for managing employees, attendance, departments, leave requests, company documents, and day-to-day operations through an intuitive admin dashboard.

## ✨ Features

- Employee management
- Attendance tracking
- Department management
- Leave request management
- Daily work report submission
- Role-based authentication (Admin & Employee)
- Company settings management
- Dashboard with analytics and reports
- Document management
- Responsive user interface

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/junaid0x/EMS.git
```

### Install dependencies

```bash
# Client
cd client
npm install

# Server
cd ../server
npm install
```

### Configure Environment Variables

Create a `.env` file inside the `server` directory and configure your database credentials and application settings.

### Run the project

```bash
# Backend
npm run dev

# Frontend
npm run dev
```
